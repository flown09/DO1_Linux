- Он не связан с каким-либо физическим оборудованием и служит для тестирования и внутренней связи.

- Без loopback-интерфейса многие локальные сетевые сервисы не будут работать, потому что они используют его для взаимодействия.

## Part 8. Установка и базовая настройка сервиса SSHD

- Установим службу SSHD с помощью команды sudo apt install openssh-server -y.

- С помощью команды sudo systemctl enable sshd --now добавим автостарт службы при загрузке системы.

- С помощью команды sudo vim /etc/ssh/sshd_config откроем файл и заменим строку #Port 22 на Port 2022.

- На рисунке 8_1 показана команда, которая показывает наличие процесса sshd, и ее вывод.

![Рисунок 8_1 - процесс sshd](./pics/Part8_1.png)

1. ps — команда для отображения информации о процессах.
2. a — показывает процессы всех пользователей.
3. u — выводит данные о пользователе, владельце процесса.
4. x — включает процессы, не связанные с терминалом.
5. | — передаёт вывод одной команды на вход другой (фильтрация).
6. grep sshd — фильтрует только строки, содержащие "sshd".

- Перезагрузим систему с помощью команды sudo reboot now.

- Вывод команды netstat -tan показан на рисунке 8_2 

![Рисунок 8_2 - вывод netstat -tan](./pics/Part8_2.png)

1. t — выводит только TCP-соединения.
2. a — отображает все соединения (включая те, которые находятся в состоянии LISTEN).
3. n — отображает IP-адреса и порты в числовом виде (без разрешения DNS-имен).

- Proto (Протокол) указывает используемый сетевой протокол (TCP или TCP6).

- Recv-Q (Receive Queue) - это количество данных (в байтах), которые уже приняты сетевым стеком устройства, но ещё не обработаны приложением.

- Send-Q (Send Queue) - это количество данных (в байтах), которые программа уже отправила в сокет, но которые ещё не подтверждены удалённым устройством.

- Local Address (Локальный адрес) IP-адрес и порт на локальной машине, на которых открыт сокет.

- Foreign Address (Удалённый адрес)	IP-адрес и порт удалённого узла, с которым установлено соединение. 0.0.0.0:* означает, что принимаются соединения от любых адресов.

- State (Состояние соединения) текущее состояние соединения.

- 0.0.0.0 - это специальный IP-адрес, означающий "все доступные интерфейсы"

## Part 9. Установка и использование утилит top, htop

- Установим top и htop с помощью команды sudo apt install procps htop -y

- Запустим top. Вывод показан на рисунке 9_1

![Рисунок 9_1 - запуск top](./pics/Part9_1.png)

- Uptime (время работы системы) равно 19 минут

- User (количество авторизованных пользователей) 1

- Load average (средняя загрузка системы) 0.75 0.69 0.67

- Tasks (общее кол-во процессов) 150

- %Cpu(s) (загрузка cpu) 
1. us — (User CPU time) время, затраченное на работу программ пользователей 2.7
2. sy — (System CPU time) время, затраченное на работу процессов ядра 3.3
3. ni — (Nice CPU time) время, затраченное на работу программ с измененным приоритетом 0.0
4. id — простой процессора 93.8
5. wa — (iowait) время, затраченное на завершение ввода-вывода 0.1
6. hi — (Hardware IRQ) время, затраченное на обработку hardware-прерываний 0.0
7. si — (Software Interrupts) время, затраченное на работу обработку software-прерываний (network) 0.2
8. st — (Steal Time) время, «украденное» гипервизором у этой виртуальной машины для других задач 0.0

- Mem (оперативная память) 7945.5 всего, 3883.3 свободно, 789.3 занято

- Swap (файл или раздел подкачки) 4096.0 всего, 4096.0 свободно, 0 занято

- Для нахождения pid процесса, занимающего больше всего памяти нажмем Shift + M. Произойдет сортировка по памяти (столбец RES). pid = 10463

- Для нахождения pid процесса, занимающего больше всего процессорного времени нажмем Shift + P. Произойдет сортировка по CPU (столбец %CPU). pid = 10463
